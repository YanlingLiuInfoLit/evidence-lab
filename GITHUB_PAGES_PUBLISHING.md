# Publish Evidence Lab with GitHub Pages

1. Create a new public GitHub repository, for example `evidence-lab`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save. GitHub will provide the public site URL.
7. Add that URL to `cite.html` and the preferred citation.
8. Before public launch, finalize the CC BY 4.0 content notice and MIT code license and confirm rights for the four visual assets.

The `play.html` edition is intentionally static/formative and works on GitHub Pages. It is not intended for protected high-stakes assessment because scoring metadata necessarily runs in the browser.

The secure server architecture remains available separately for future authenticated/graded use.
